# 🛍️ React Ecommerce Website

A modern and responsive ecommerce web application built with **React** and **Vite**, allowing users to browse products by category and gender, view product details, and manage a shopping cart—all within a smooth and clean user interface.

---

## 🚀 Features

- ⚛️ **React + Vite** for blazing-fast development and optimized builds
- 📱 **Responsive layout** with a mobile-friendly hamburger menu
- 🧭 **Sticky Navbar** with dynamic navigation and filtering
- 🛍️ **Product catalog** with filtering by **category** (Footwear, Apparel, Accessories) and **gender** (Men, Women, All)
- 🖼️ **Interactive product cards** with hover animations
- 🧾 **Product details page** with “Add to Cart” functionality
- 🛒 **Shopping cart** with quantity management, total calculation, and item removal
- 🔥 Clean and modern UI built with plain CSS

---

## 🧰 Tech Stack

- **React**
- **Vite**
- **JavaScript**
- **HTML & CSS**

## 📦 Getting Started

Follow the steps below to set up the project locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/matifelitti/React-Ecommerce-Website.git
   cd React-Ecommerce-Website
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

4. **View the app**

   Open your browser and navigate to:
   [http://localhost:5173](http://localhost:5173)
