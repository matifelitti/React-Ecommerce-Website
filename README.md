# 🛍️ React Ecommerce Website

A modern, responsive ecommerce web application built with **React**. It allows users to browse a catalog of products with dynamic filtering by **category** and **gender**, a clean layout, and smooth user interactions.

## ✨ Features

- ⚛️ Built with React and Vite for fast development and performance
- 📱 Fully responsive design with mobile-friendly navigation
- 🧭 Fixed navbar with hamburger menu on small screens
- 🎯 Filter products by **category** (Footwear, Apparel, Accessories)
- 🚻 Filter by **gender** (Men, Women, All)
- 🖼️ Image-based product cards with hover animations
- 💅 Styled using clean, modern CSS

## 🚀 Getting Started

Follow these steps to get the project up and running locally.

1. **Clone the repository:**

   ```bash
   git clone https://github.com/matifelitti/React-Ecommerce-Website.git
   cd React-Ecommerce-Website

   ```

2. **Install dependencies:**

   ```bash
   npm install

   ```

3. **Start the development server:**

   ```bash
   npm run dev

   ```

4. **Open the app:**

   Visit http://localhost:5173 in your browser.
